# AI Audit Tool — Маркетинговый аудит сайтов

Локальное приложение для быстрого аудита сайтов с расчётом финансовых потерь.

## 🚀 Быстрый старт

### Windows
1. Открой папку в проводнике
2. Дважды кликни `start.bat`
3. Браузер откроется автоматически на http://localhost:5000

### Linux/Mac
```bash
chmod +x start.sh
./start.sh
```

## 📋 Требования
- Python 3.11+ (уже установлен ✅)
- Интернет для API запросов

## 🛠️ Ручная установка (если скрипт не работает)

```bash
# 1. Создай виртуальное окружение
python3 -m venv venv

# 2. Активируй его
source venv/bin/activate  # Linux/Mac
# ИЛИ
venv\Scripts\activate.bat  # Windows

# 3. Установи зависимости
pip install -r requirements.txt

# 4. Запусти сервер
python server.py

# 5. Открой в браузере
http://localhost:5000
```

## 📝 Как использовать
1. Открой http://localhost:5000 в браузере
2. Введи URL сайта клиента
3. (Опционально) Укажи трафик и средний чек для расчёта потерь
4. Нажми "🚀 Проверить сайт"
5. Получи детальный аудит с финансовым прогнозом

## 🔐 Безопасность
API ключи Jina AI и Polza AI защищены на backend — не видны в браузере.

## 🐛 Проблемы?
- Порт 5000 занят? Измени в `server.py`: `app.run(port=5001)`
- Ошибка импорта? Переустанови: `pip install -r requirements.txt --force-reinstall`
