# AI Audit Tool — Профессиональный маркетинговый аудит сайтов

Локальное приложение для глубокого аудита сайтов с расчётом финансовых потерь и сравнением с конкурентами.

## 🚀 Быстрый старт

### Windows
1. Дважды кликни `start.bat`
2. Браузер откроется автоматически на http://localhost:5000

### Linux/Mac
```bash
chmod +x start.sh
./start.sh
```

## 🌟 Возможности

### 📊 Быстрый аудит
- Анализ сайта на 20+ параметров маркетинговой упаковки
- Счётчики проблем (критичные/важные/минорные)
- Расчёт финансовых потерь для КАЖДОЙ проблемы
- Детальные рекомендации с примерами
- Автоматический расчёт потенциальной конверсии

### ⚔️ Битва сайтов
- Сравнение сайта клиента с конкурентом
- Визуализация разницы по всем параметрам
- Финансовое сравнение (сколько конкурент забирает денег)
- Готовая аргументация для клиента

### 📄 Отчёт для клиента
- Генерация профессионального HTML отчёта
- Формат для печати/отправки
- Копирование в буфер обмена
- Готовый отчёт можно вставить в Word/Google Docs → сохранить как PDF

### 💰 Финансовый прогноз
- График потерь по месяцам и кварталам
- Рейтинг по отраслевым бенчмаркам
- ROI прогноз: сколько получит бизнес от исправлений
- Интерактивный калькулятор с live обновлением

## 🔐 Безопасность
API ключи Jina AI и Polza AI защищены на backend — не видны в браузере.

## 📋 Требования
- Python 3.11+ (✅ уже установлен)
- Интернет для API запросов

## 🛠️ Ручная установка (если скрипт не работает)

```bash
# 1. Создай виртуальное окружение
python -m venv venv

# 2. Активируй его
venv\Scripts\activate.bat  # Windows
# ИЛИ
source venv/bin/activate   # Linux/Mac

# 3. Установи зависимости
pip install -r requirements.txt

# 4. Запусти сервер
python server.py

# 5. Открой в браузере
http://localhost:5000
```

## 📝 Как использовать

### Быстрый аудит
1. Открой http://localhost:5000 в браузере
2. Введи URL сайта клиента
3. (Опционально) Укажи трафик и средний чек для расчёта потерь
4. Нажми "🚀 Проверить сайт"
5. Получи детальный аудит с финансовыми потерями для каждой проблемы

### Битва сайтов
1. Переключись на таб "Битва сайтов"
2. Введи URL сайта клиента и конкурента
3. Укажи трафик и средний чек
4. Нажми "⚔️ Сравнить сайты"
5. Получи сравнение и аргументы для клиента

### Финансовый прогноз
1. Проведи быстрый аудит
2. Переключись на таб "💰 Финансовый прогноз"
3. Изучи графики потерь, бенчмарки, ROI
4. Используй интерактивный калькулятор для сценариев

### Отчёт для клиента
1. Проведи быстрый аудит
2. Переключись на таб "Отчёт для клиента"
3. Нажми "📄 Сформировать отчёт"
4. Нажми "📋 Скопировать отчёт"
5. Вставь в Word/Google Docs и сохрани как PDF

## 🐛 Проблемы?

- **Порт 5000 занят?** Измени в `server.py`: `app.run(port=5001)`
- **Ошибка импорта?** Переустанови: `pip install -r requirements.txt --force-reinstall`
- **График не отображается?** Проверь, что Chart.js загрузился (DevTools → Console)

## 💡 Фишки

- **Расчёт потерь для каждой проблемы**: покажи клиенту, что конкретно эта кнопка стоит ему 500k₽/год
- **Сравнение с конкурентом**: "Ваш конкурент забирает у вас 2.5М₽/год из-за лучшей упаковки"
- **Бенчмарки**: "Ваш сайт в топ-40% по нише, но до топ-10% всего 3 исправления"
- **Интерактивный калькулятор**: подбери параметры под конкретный бизнес клиента

## 🏗️ Архитектура

- **Backend**: Flask (Python) с защищёнными API ключами
- **Frontend**: HTML/CSS/JavaScript с Chart.js для графиков
- **API**: Jina AI (парсинг сайтов) + Polza AI (анализ)
- **Безопасность**: API ключи хранятся только на сервере
